# 보카이브 실습 앱

도서(Dragon Masters #1) 단어로 공부하는 보카 학습 앱의 실습 버전입니다. 빌드 도구 없이 HTML/CSS/JS만으로 동작합니다.

## 실행

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

브라우저에서 http://localhost:5173 을 엽니다. 휴대폰 크기(개발자 도구의 모바일 보기)로 보는 것을 권장합니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 진입 페이지 |
| `styles.css` | 인디고 테마(시안 B 컬러 4) 스타일 |
| `app.js` | 화면, 라우팅, 퀴즈 로직, 저장 |
| `data/dragon-masters-1.js` | 단어 데이터 130개 (`dragon-masters-1.json`에서 생성) |
| `serve.ps1` | Node/Python 없이 쓰는 로컬 서버 |

## 학습 흐름

로그인/회원가입 → 홈 → 도서 Day 목록 → 단어 카드 → 카드 뒤집기(라운드마다 6장 = 3쌍, 3초 미리 보기 후 뒤집힘, 영단어↔뜻 짝 맞추기, 완료 +10 XP, 실수가 전체 쌍 수 이하면 +10 추가) → 퀴즈 10문제(뜻 고르기, 단어 고르기, 예문 빈칸) → 틀린 단어 재출제 → 줄거리 문제(Day 2부터) → 결과 → 아카이브

- XP: 첫 시도 정답 1개당 10, Day 완료 20, 줄거리 정답 10, 콤보(3연속부터 정답마다 +5), 퍼펙트(10/10) 20
- 레벨: Lv.1→2에 100 XP, 이후 레벨마다 필요 XP가 50씩 증가
- 오늘의 목표: 하루 50 XP (홈 화면 링)
- 배지 9종: 첫 발자국, 퍼펙트, 콤보 마스터(5연속), 꾸준함(3일), 일주일 개근(7일), 오늘 목표 달성, 단어 수집가(50장), 복습왕(복습으로 10개), 한 권 완독
- 효과음(웹 오디오 합성)과 색종이 효과, 프로필에서 효과음 끄기 가능
- `http://localhost:5173/?demo` 로 열면 로그인 없이 체험 (기록 저장 안 됨)
- 틀린 단어는 "다시 볼 단어"로 모이고, 복습 탭에서 맞히면 빠집니다.
- 줄거리 문제의 오답 보기는 이미 읽은 앞 챕터에서만 골라 스포일러를 막습니다.

## 로그인과 저장 (Supabase)

- 인증: Supabase Auth 이메일/비밀번호 (`config.js`에 프로젝트 URL과 publishable key)
- 학습 기록: `public.vocaive_progress` 테이블 (사용자당 1행, RLS로 본인 행만 읽기/쓰기)
- 현재 Supabase "Quiz" 프로젝트를 함께 쓰고 있어서, 가입하면 그 프로젝트의 가입 트리거가 `profiles`에 닉네임(이름)을 만듭니다. 그래서 이름은 2~12자, 다른 사용자와 겹치지 않아야 합니다.
- Supabase 대시보드 > Authentication > URL Configuration에 `http://localhost:5173`을 Redirect URL로 추가해야 인증 메일 링크가 앱으로 돌아옵니다.

## 실습용 제한

- 발음은 브라우저 음성 합성(TTS)을 사용합니다.
- 단어 뜻과 예문은 검수 전 데이터입니다.
